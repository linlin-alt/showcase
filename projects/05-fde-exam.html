05 · FDE 备考

230 道题、六大专题、错题本、模拟考、学习手册——一个不用装 App、换设备能接着刷的备考站。

一句话： 为腾讯云 FDE（前沿部署工程师）认证做的刷题应用，纯静态、无构建、原生 ES Modules。

问题

备考工具有两个通病：

  • 题库绑在某个 App 里，解析不能改、错题不能导、手机上刷完电脑上重来；
  • 做个刷题站要上框架、走构建，改一道题要重新 npm build。

我要的是：改一个 JSON 就多一道题，手机加到主屏就能刷。

做法

四种题型都要，不是只有选择。 单选、多选、判断、简答。简答不判对错，只给自己看解析——因为 FDE 的真题里，说不清和不知道一样致命。

解析里的英文术语可点。 点开就是这个术语的释义，不打断答题节奏。这一条是刷题时最烦的地方，专门做的。

学习手册和题库分开。 36 条口诀（翻卡记忆）+ 24 条读者问答 + 60 条名词解释，按 8 个方向分。刷累了换一种输入方式。

题库可导入可导出。 JSON / 文本模板批量导入，导出成文件带走。第一次登录自动导入 30 道内置题，另有「FDE 参考题库（200 题）」一键导入。

我的角色

独立完成：题库整理、产品设计、实现、上线。

技术

  • 原生 ES Modules + 原生 CSS，零构建、零第三方前端框架
  • hash 路由（js/router.js），手机 / 平板 / 桌面自适应
  • 云服务：手机号 / 邮箱验证码登录，答题记录、错题、口诀进度按用户隔离存云端
  • 题库与代码分离，JSON 直接改

现状

230 题在线可刷（30 道公开笔试题型改编 + 200 道参考题库，六大专题：生成式 AI 基础 / RAG 检索增强 / ADP 产品能力 / 行业方案设计 / 安全合规 / 工程实践综合）。

FDE 没有官方公开真题，题库是公开题型改编与整理，用于查漏补缺——这句话写在 README 里，不吹。
