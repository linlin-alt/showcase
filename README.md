## 我怎么工作

**先问清楚，再动手。**
康伴那条业务链——四个角色、八步流程、五个能当场演示的闭环——是坐在桌子对面一句句问出来的，不是想出来的。问错一步，后面全白做。

**重活放本地，AI 只干该它干的。**
照片工坊一万张照片，扫描、分类、聚类、精选全在你自己的电脑上跑，一分钱不花；只有「看图写文案」这一步调模型，调用次数等于地点数（几百），不是照片数（上万）。这个取舍是我做的。

**能跑 > 好看。**
每个项目都有一句话能说清的最小闭环，先让这条线通到底，再谈别的。

**AI 是工具，不是挡箭牌。**
我用 AI 写代码，这件事我从第一天就说。我的价值在前半段：谁在痛、谁付钱、哪一步最烦。

## 关于源码：什么公开，什么不公开

这套作品集里只有说明、图片和链接，**没有一行生产代码**。原因是其中几个仓库里装着不该公开的东西——不是怕被抄，是里面有别人的信息。

| 仓库类型 | 里面有什么 | 为什么不能公开 |
|---|---|---|
| 个人数据系统（04） | 本地数据库，一条记录一个文件，含日记、收支、身体数据、人际往来 | 含**第三方**的姓名与私事。不是我的隐私问题，是别人的 |
| 本机工具与配置备份 | 定时任务、运行环境、配置文件 | 含环境信息与凭据，公开等于把钥匙拍照发出去 |
| 个人知识库 | 阅读笔记与长期档案 | 与作品无关，且大量摘录内容版权不清 |
| 客户项目（02） | 代码与业务数据 | 归属客户，我不单方面公开 |

需要看代码的时候，开权限或当面看——**这件事我写在最前面，不等你问。**
